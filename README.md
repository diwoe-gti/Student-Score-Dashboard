# Student Score Dashboard

เว็บแอปจัดการคะแนนนักเรียนด้วย Python และ Streamlit

## ทดลองในเครื่อง
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Deploy ฟรี
1. เปิด https://share.streamlit.io/
2. Sign in ด้วย GitHub และอนุญาต repository นี้
3. เลือก repository `diwoe-gti/Student-Score-Dashboard`
4. เลือก branch `main` และ Main file path `app.py`
5. กด Deploy

หมายเหตุ: เวอร์ชันเริ่มต้นนี้เก็บข้อมูลใน Streamlit session ของผู้ใช้แต่ละคน ข้อมูลไม่ใช่ฐานข้อมูลถาวรและอาจหายเมื่อเซสชันสิ้นสุด เหมาะสำหรับทดลองใช้งานก่อนเชื่อมฐานข้อมูลจริง
